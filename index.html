Тренировки

Выбирай день, вписывай упражнения и аналоги, а кнопка ниже будет собирать случайную тренировку. Все данные сохраняются прямо в браузере.

Активный день: Спина + трицепс Подсказка: в "Аналоги" можно писать через запятую.

Спина + трицепс

Заполни список упражнений. Потом генератор выберет случайную версию из аналога и соберет тренировку.

Упражнение
Аналоги
Подходы / повторы
Пример: Тяга верхнего блока / аналоги: подтягивания, тяга резинки / 3x10-12.

Ноги

Отдельный день для ног. Можно настроить любой набор упражнений и замен.

Упражнение
Аналоги
Подходы / повторы
Пример: Присед / аналоги: жим ногами, гакк-присед / 4x6-10.

Грудь + руки

Сюда можно добавить жимы, разводки, бицепс и все твои замены.

Упражнение
Аналоги
Подходы / повторы
Пример: Жим штанги лежа / аналоги: жим гантелей, жим в тренажере / 4x6-10.
